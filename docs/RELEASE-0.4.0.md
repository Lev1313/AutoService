# AutoService 0.4.0 — 14 ноября 2026

Поручение «сделай что перечислил кроме сервисного листа» выполнено для всех четырёх
оставшихся пунктов плана. Сервисный лист не разрабатывался.

## Изменения
- Прежний пробег предлагается с ?, датой исходного замера и явным подтверждением нового.
  Запись задним числом не берёт будущий замер. Прежнее число сохраняется как снимок,
  не создаёт замер для ТО и присутствует с пометкой в истории, новых PDF и выгрузках.
- Ремонт удаляется с подтверждением (по умолчанию отмена), показывается среди удалённых
  и восстанавливается. PDF/оригиналы TXT/связи остаются. Повторный импорт не оживляет его.
  Замер удалённого ремонта исключён из актуального пробега. Отдельные выполненные ТО
  и их замеры сохраняются; предупреждение перечисляет связи. Конфликт при восстановлении
  требует явного выбора неподтверждённого замера, исходное число не теряется.
- Один раздел Звонки: список и календарная сетка, выбор дня и общие результаты/переносы.
  Без даты — «Уточнить срок»; обработанные доступны фильтром. Боковой дубль удалён.
- Настройки → «Экспорт базы в TXT / Excel»: новая папка, все 19 таблиц/ID/флаги,
  20 листов Excel с описанием, точные суммы и неизвестные значения, полный текст,
  история по автомобилям в TXT, data.json и manifest.json с составом и SHA256.
  По умолчанию включены оригинальные TXT и выданные PDF, их байты проверены по хешу.
  Длинные и неподдерживаемые Excel тексты — целиком в texts/ со ссылками из книги.
  Пользовательские строки не исполняются как формулы, телефоны/VIN остаются текстом.
  Рабочая база открывается только для чтения, одна транзакция снимка, готовая папка
  появляется после успешного завершения. Существующие выгрузки не заменяются.

## Проверено
- 103 теста pytest; Ruff и форматирование. Сохранение, перезапуск, миграция v5→v6
  с защитной копией и откатом ошибки, backup/restore с архивами, отмена удаления,
  самостоятельные отметки ТО, повтор импорта, восстановление противоречивого пробега.
- Согласованный снимок при параллельной записи в отдельной синтетической WAL-базе,
  ошибка диска без готовой частичной выгрузки, временная блокировка папки Windows,
  тексты >32767 символов/Unicode, точные CRLF, ограничения строк Excel и текстовые формулы.
- Настоящие окна Qt/Windows при обычном масштабе и дополнительном ×1,5: перенос
  пробега, история/удаление/восстановление, архив PDF, календарь/результат и экспорт.
- Самостоятельный собранный EXE: миграция v2→v6, клиенты, ремонты, пробег ?, удалённый
  TXT, защита повтора, PDF, TXT/XLSX, backup/restore и второй отдельный запуск.
- Очищенные PATH/PYTHONHOME/PYTHONPATH, Python/Qt загружены из _internal, второй обычный
  экземпляр блокируется, все процессы завершились штатно. Путь печати выведен в PDF.
- Установка, повторная установка и удаление проверочного Setup в отдельную папку:
  синтетическая база сохранена. Владелец уже установил AutoService, поэтому проверочный
  Setup собран тем же Inno-скриптом из того же payload с отдельным AppId. Основная
  регистрация установки проверена до/после и не изменилась. Владельцу выдаётся обычный
  Setup с прежним основным AppId; проверочный Setup не выдаётся.
- XLSX из собранного EXE независимо прочитан openpyxl 3.1.5: 20 листов, все записи,
  пометки и текстовые поля, формулы отсутствуют. openpyxl в программу не добавлен.
- Сверены 276 файлов манифеста, целостность ZIP и совпадение его payload.
  Примеси ICU нет. Инструкция актуальна (Настройки — Ctrl+5) и включена в оба пакета.

## Обновление владельцем
Сделать обычную внешнюю резервную копию, закрыть AutoService и запустить Setup 0.4.0.
База хранится отдельно от программы; при первом запуске схема v5 обновится до v6
с дополнительной защитной копией. Не возвращать старую программу к уже обновлённой базе.
Все проверки разработчика использовали только вымышленные данные. Рабочая база не открывалась.

## Известные ограничения
Тесты выполнены на текущем Windows-компьютере, отдельного чистого компьютера не было.
Книга проверена независимой библиотекой; установленный Microsoft Excel отдельно не запускался.
Установщик без подписи издателя. Физическая HP-печать подтверждена раньше; в этой итерации
проверены PDF/предпросмотр и программный путь печати, новый физический лист не печатался.
Настоящий архив TXT и исходный Word/PDF-бланк пока не получены, их совместимость не обещается.
Экспорт TXT/Excel предназначен для чтения/передачи; восстанавливается отдельная SQLite-копия.
Склад, финансы, многопользовательский режим, облако и новые неподтверждённые функции не добавлены.
Общая первоначальная Goal всё ещё зависит от материалов C1b/D1b; текущая итерация завершена.
