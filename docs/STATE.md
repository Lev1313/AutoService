Не объявлять всю цель выполненной по готовности одного этапа.

## Готово
A0–A4: автомобили, контакты, поиск, карточка, текущие/завершённые ремонты,
отдельные замеры, защита несохранённых форм, горячие клавиши, backup/restore.
B1–B3: настраиваемые правила ТО, явное выполнение, расчёт по дате/км,
Главная и Календарь со списком звонков, перенос/не дозвонились/связались/отказ/возврат.
Одна задача на цикл; ручная дата сохраняется, отказ действует и для новых правил машины.
Схема v3. Восстановление поддерживает v1–v3, старую копию мигрирует отдельно от оригинала.

## Проверено
42 теста pytest: сохранность после перезапуска, миграции и откат, деньги, контакты,
формы и клавиатура, месяцы/високосный год, расчёт от последнего замера, неполные данные,
переносы/отказы/циклы, отсутствие автосброса по тексту, backup/restore старой схемы.
Ruff и проверка форматирования пройдены. Процесс тестов завершается без ошибок.
Формы календаря/правила/выполнения/звонка просмотрены через обычное отображение Windows,
при обычном масштабе и дополнительном увеличении ×1,5.
Все проверки — на вымышленных данных и отдельных БД. Рабочая база не открывалась.
При обычном запуске новая версия сама создаст копию перед обновлением старой базы.
Календарь сохраняется отдельной локальной контрольной версией; сверяй фактический Git.
