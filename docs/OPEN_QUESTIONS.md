# Вопросы владельцу

Не задавать повторно, если ответ уже есть в новом сообщении; сначала проверить его.
Пустой ответ не означает согласия с предложенным вариантом.

1. Календарь: какие виды ТО нужны первыми, интервалы в месяцах/километрах,
   за сколько дней звонить? Пока можно создавать механизм настройки без значений.
2. Как отмечать результат звонка: записан, позже, не дозвонились?
   Сначала подготовить простой предлагаемый вариант, не раздувать статусы.
3. Квитанции: реальный бланк, реквизиты и поля подробной строки.
   Пока оба формата подтверждены, юридическое назначение не определено.
4. TXT: исходные полные файлы разных вариантов и кодировок. До их получения
   не заявлять о готовности импорта реальных архивов.
5. Где хранить внешнюю копию: другой диск или флешка? Папка выбирается в Настройках.
6. При пилоте: владелец оценивает добавление машины, запись ремонта, поиск и чтение
   длинной истории. Технические проверки делает разработчик.
