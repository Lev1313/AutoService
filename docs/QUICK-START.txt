AutoService 0.5.0 — начать работу

ПЕРВЫЙ ПОКАЗ МЕХАНИКУ
Откройте «Показ механику (отдельные данные)» из меню «Пуск».
В распакованном ZIP откройте «Показ механику.cmd».
Вверху слева будет «Показ механику · отдельные данные».
Введите вымышленные машину и клиента. Пробные записи сохранятся для следующего показа,
но не попадут в обычную рабочую базу. Обычный ярлык AutoService открывает рабочие данные.
Режим показа изначально пустой; готовые машины и реальные интервалы ТО не подставляются.

1. ДОБАВИТЬ МАШИНУ
«Автомобили» → «Добавить автомобиль». Достаточно марки, модели, госномера или VIN.
Остальное можно заполнить позже. Имя и телефон клиента необязательны.
Подсказку можно выбрать или ввести своё значение. Нажмите «Сохранить».

2. ЗАПИСАТЬ РАБОТУ
В карточке машины нажмите «Добавить ремонт». Введите дату и что сделано.
Пробег и стоимость можно оставить пустыми; 0 рублей означает бесплатную работу.
СОХРАНИТЬ — оставить ремонт текущим и вернуться к нему позже.
ЗАВЕРШИТЬ РЕМОНТ — поместить его в завершённую историю. Это не отметка об оплате.
Старый пробег с ? — прежний замер, а не новый. Подтвердите только измеренный пробег.

3. НАЙТИ И ИСПРАВИТЬ
В «Автомобилях» ищите по номеру, марке, модели, VIN, имени или телефону.
Двойной щелчок открывает карточку. В ней выберите ремонт и откройте его.
Длинный текст виден под таблицей истории. Ошибочную запись можно удалить с подтверждением;
«Показать удалённые ремонты» позволяет её восстановить.

4. ПОКАЗАТЬ КВИТАНЦИЮ
В карточке машины выберите сохранённый ремонт → «Документы / Печать».
Сначала «Предпросмотр». Для выдачи нажмите «Сохранить экземпляр», затем «Сохранить PDF» или «Печать».
Сохранённый экземпляр остаётся прежним после правок ремонта; исправленный оформляется новым.

5. ЗАКОНЧИТЬ РАБОТУ
«Настройки» → «Создать резервную копию» → выберите другой диск или флешку.
TXT/Excel — выгрузка для чтения. Для восстановления нужна именно резервная копия базы.
Копия, сделанная в режиме показа, содержит только пробные данные этого режима.

ПОД РУКОЙ
F1 — эта инструкция; Esc — закрыть форму с проверкой несохранённых изменений.
Ctrl+F — поиск в открытых «Автомобилях» или «Клиентах»; из других разделов — поиск машин.
Ctrl+S — сохранить форму. Ctrl+1 — автомобили, Ctrl+2 — клиенты,
Ctrl+3 — звонки, Ctrl+4 — настройки.
ТО и звонки, импорт TXT, экспорт и восстановление описаны на вкладке «Все действия».
