## Оставшиеся внешние проверки

- Пользователь сообщил, что реальных TXT и образца квитанции пока нет.
  Разбор именно его архива и соответствие именно его бланку не проверены.
- Отдельный чистый компьютер, другие версии Windows/принтеры и физическая многостраничная печать не проверены.
- Установщик без сертификата издателя; проверка SmartScreen на чистом компьютере не проводилась.
- Интервалы ТО и реквизиты вводит владелец. Удобство работы оценивается при пробе.
- Финансы, склад, облако и несколько пользователей в выпуск не входят.

Следующий шаг зависит от результатов пробы: достаточно описания затруднения/ошибки
либо реальных образцов, когда появятся. Не требовать повторно
отсутствующие материалы и не расширять функциональность ради продолжения Goal.

## Дополнение: физическая печать после выпуска

10 ноября пользователь подключил HP по USB. Отправлена ровно одна страница вымышленной
подробной квитанции через app.ui.documents.print_pdf и QPrinter из основного проекта.
PDF взят из проверки установленного выпуска; его SHA256:
e14d13ec9afc7ad6a2e90f002427814fd68cc7115fb12b77d0841fc434603b9e.
Windows показала Spooling → Printing; после обработки тестовых заданий не осталось.
Пользователь подтвердил: «Да, всё читается и помещается». Сам EXE ранее проверен
выводом в PDF; физическая проба функции выполнена из исходников на той же версии Qt.
Код и файлы Setup/ZIP не менялись; исходная инструкция внутри них отражает момент сборки.
Отдельная инструкция и этот отчёт обновлены. Владелец программу ещё не пробовал.
