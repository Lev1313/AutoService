## Практические ограничения

- Само нажатие F5 в интерфейсе VS Code не автоматизировалось: проверены настройки,
  наличие отладчика и запуск компонентов Qt. Пользователю остаётся оценить окно.
- Python 3.14 фактически не проверялся: используется уже установленный 3.13.1.
- Рабочая база в AppData не затрагивалась во время тестирования. Она создастся
  при первом обычном запуске. Тестовые базы находятся в временных каталогах
  pytest и в исключённом из Git каталоге `artifacts/`.
- Первичная папка `.git` оказалась создана от имени sandbox. Пустые метаданные
  сохранены в `artifacts/git-initialization-backup`; репозиторий повторно создан
  от имени пользователя Windows. Глобальные настройки доверия Git не менялись.
- Для части команд потребовался запуск вне sandbox из-за ошибки его настройки.
  Права всего компьютера и политика выполнения PowerShell не менялись.

Официальные источники параметров приведены в README. Полное ТЗ и ER-модель
пока отсутствуют; `docs/requirements.md` явно помечен как предварительный.
