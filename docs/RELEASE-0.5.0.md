# AutoService 0.5.0 — первый показ механику

Дата: 15 ноября 2026. Выпуск для самостоятельной пробы и сбора обратной связи.

## Изменения
- Удалён раздел-заглушка Финансы. Четыре раздела: Автомобили, Клиенты, Звонки, Настройки.
- F1 и кнопка в боковой панели открывают только быстрый старт и полную инструкцию.
  Тексты читаются из локальных файлов, работают без интернета и не меняют базу.
- Ctrl+F сохраняет текущий раздел при поиске клиентов; из остальных разделов ищет машины.
- Возврат в список сохраняет выделенную машину/клиента, если запись ещё видна.
  Пустые списки объясняют первый шаг; Звонки объясняют назначение и фильтры.
- Отдельный запуск --demo: пустая база AutoService-Demo, видимая отметка режима,
  отдельная блокировка. Учебные записи сохраняются; рабочая база обычного запуска прежняя.
  В ZIP есть Показ механику.cmd, установщик добавляет отдельный ярлык в Пуск.
- Обновлена инструкция; добавлены быстрый старт, сценарий показа на 25–35 минут,
  вопросы о привычной работе/удобстве/нужности функций и карточка замечания.
  Финансы и склад включены только как вопросы о потребности.

Стоимость ремонта и позиции квитанции сохранены. Финансовый/складской модуль не создан.
Схема остаётся v6; новая миграция не нужна. Сервисный лист не входит в выпуск.

## Проверки
- 105 тестов pytest прошли, Ruff и проверка форматирования — без ошибок.
  Новые проверки: изоляция и сохранность демобазы, неизменность отдельной рабочей тестовой
  базы, четыре раздела, Ctrl+4, поиск клиентов, выделение после навигации, F1 без записи.
- Существующая проверка временной блокировки Windows один раз встретила дополнительную
  реальную блокировку папки (3 попытки вместо ожидаемых 2). Повторный полный прогон прошёл;
  код экспорта не менялся. Ограничение нестабильного счётчика попыток не скрывается.
- Автономный EXE: миграция v2→v6 с копией, клиенты/ремонт/ТО/звонок, PDF/печать в PDF,
  TXT/повторы/архив, TXT/XLSX-выгрузки, backup/restore и повторное чтение отдельным процессом.
  Сборка проверяет наличие обеих инструкций и четыре раздела.
- Обычный запуск EXE с ограниченным PATH и очищенными PYTHONHOME/PYTHONPATH:
  Python/Qt загружены из _internal; второй экземпляр того же режима блокируется.
- Установка, повторная установка, запуск установленного EXE и удаление проверены
  с отдельным проверочным AppId, папкой и LOCALAPPDATA. Контрольные суммы тестовой базы
  до/после операций совпали; регистрация основной установки не изменилась.
- Настоящее окно собранного EXE --demo просмотрено в Windows: четыре раздела, пометка
  режима, путь базы в Настройках, помощь F1 с двумя вкладками инструкций. Старт и помощь проверены
  при обычном масштабе и дополнительном ×1,5; текст переносится, доступны прокрутка/закрытие.
- Все данные проверок вымышлены. Реальная рабочая база не открывалась и не менялась.

## Ограничения и следующий шаг
Механик эту версию ещё не пробовал; удобство для его реальной работы не подтверждено.
Провести SHOW-GUIDE.txt и заполнить MECHANIC-FEEDBACK.txt, затем выбрать приоритеты правок.
Ответы о финансах/складе не получены, разработка этих модулей не начата.
Реальный TXT-архив не проверен. На отдельном чистом компьютере проверки не было.
Microsoft Excel и физический принтер заново не запускались; путь печати проверен в PDF.
Установщик без подписи издателя. Защиту Windows не отключать при блокировке запуска.
Обычная установленная программа владельца автоматически не обновлялась.
Текущая итерация подготовки завершена; встреча и её ответы остаются отдельным следующим шагом.
