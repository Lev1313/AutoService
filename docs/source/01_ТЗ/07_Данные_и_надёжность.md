# Черновик модели данных и надёжности

## Сущности (концепция, не SQL-схема)
- **Клиент**: ID, имя/обозначение, телефон, комментарий, контактные предпочтения/согласия при необходимости.
- **Автомобиль**: ID, марка/модель, госномер, VIN (необязательно), владелец/контакт.
- **История принадлежности авто**: при необходимости смена клиента без потери ремонтов.
- **Ремонт**: ID, автомобиль, дата, пробег на визите, текст, итоговая стоимость, завершён/не завершён, источник.
- **Замер одометра**: ID, автомобиль, дата, км, источник, отметка достоверности.
- **Вид ТО**: ID, название, рекомендуемый временной и километровый интервал (настраиваемые).
- **Цикл ТО**: автомобиль, вид процедуры, последнее выполнение, срок/порог, прогноз, ручная корректировка.
- **Задача/звонок**: клиент/автомобиль, повод, дата, состояние и история результата.
- **Документ**: тип, номер, версия/снимок данных, дата, ссылка на ремонт, путь PDF.
- **Импорт**: файл, контрольная сумма, обработанные фрагменты, журнал ошибок, исходный текст.

## Основные связи
Клиент 1—N авто (со сменой владельцев); авто 1—N ремонтов, замеров, задач, циклов ТО; ремонт 0—N документов; импортированный файл 1—N ремонтов.

## Выбранная архитектура
Локальная настольная Windows-программа для одного человека, без облака. Предварительно: Python + PySide6 + SQLite. UI и БД отделить друг от друга, чтобы можно было переносить/тестировать логику.

## Надёжность — не откладывать
- База SQLite находится в управляемом каталоге данных, не рядом с временным EXE.
- Резервные копии не ограничивать тем же физическим диском; нужен другой диск/флешка и понятная процедура восстановления.
- Файл БД нельзя просто небрежно копировать во время записи; использовать согласованный backup-механизм SQLite.
- Сохранение незавершённой работы и обработка сбоя/ошибок на диске.
- Для удаления и массового импорта подтверждение и возможность отката по бэкапу.
- Если делается экспорт, учитывайте персональные данные клиентов.
- Возможность обновления версии программы с миграцией схемы БД и резервной копией перед этим.

## Вопросы на позже
Шифрование локальной БД, пароль запуска, режим подключения одного принтера, обновления через интернет (необязательные), автоматическое резервирование на внешний носитель.
