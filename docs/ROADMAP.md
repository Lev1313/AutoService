# План самостоятельной разработки

Приоритет: исправить регрессию → закончить начатое → следующая доступная задача.
Завершение подтверждается проверками и STATE; не количеством написанных файлов.

| ID | Задача | Состояние | Готовность |
|---|---|---|---|
| A0 | Собрать актуальное ТЗ рядом с кодом, правила и точку продолжения | Готово | Источники сохранены; основные документы согласованы между собой |
| A1 | Автомобили, контакты, поиск, карточка | Готово | Создать, найти, изменить номер/контакт; история не теряется |
| A2 | Текущий/завершённый ремонт, история, пробеги | Готово | Четыре поля; повторное открытие сохраняет текст, деньги, пробег |
| A3 | Защита базы и резервное копирование | Готово | Копия до миграции; проверенный backup/restore и снимок перед заменой |
| A4 | Проверки форм и локальная контрольная версия | Готово | 28 тестов, Ruff/форматирование, вид окон, основная папка и Git |
| B1 | Настраиваемые правила ТО и явная отметка выполнения | Следующая | Интервалы задаёт владелец; свободный текст не сбрасывает цикл |
| B2 | Расчёт сроков и список звонков | После B1 | Дата и пробег; неизвестные данные не превращаются в уверенный прогноз |
| B3 | Обработка/перенос звонков без дубликатов | После B2 | Состояние сохраняется после перезапуска |
| C1 | Простой и подробный документ | Нужен образец для окончательного вида | Снимок данных, PDF/печать, проверка сумм |
| D1 | Пробный TXT-импорт и журнал сомнений | Нужны оригиналы TXT | Превью, исходники, защита повторного импорта |
| E1 | Пилот и установочная версия | После основных модулей | Сценарии владельца, обновление, восстановление, инструкция |

В B1 допустимо сделать механизм настройки без выдуманных интервалов.
Для подтверждения реальных сценариев нужны ответы из OPEN_QUESTIONS.
Отдельная очередь идей: `source/03_Идеи_на_будущее/Backlog.md`.
Финансы и склад не добавлять автоматически в текущий этап.
