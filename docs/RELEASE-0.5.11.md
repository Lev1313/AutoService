# AutoService 0.5.11

21 ноября 2026. Локальная Windows-сборка с сервисным листом по оригиналу
«Фольц Мастер.doc», переданному владельцем для формирования документов.

Из ремонта откройте «Документ / Печать» и выберите «Фольц Мастер: сервисный лист».
Автомобиль, дата, пробег и описание подставляются из ремонта. Рекомендации вводятся
отдельно и сохраняются в черновике и выданном документе. Шапка и нижняя полоса
получены из оригинала; цены в этом варианте не выводятся. Word на рабочем компьютере
не нужен. Для отсутствующего системного Comic Sans MS программа сообщает ошибку
формирования, не выдавая документ с другим шрифтом незаметно.

Схема SQLite остаётся v7. Старые квитанции, их номера и сохранённые байты PDF
не меняются. Сервисные листы получают СЛ, квитанции — КВ в общей последовательности.
Изображение шапки содержит контакты исходного бланка; «Реквизиты сервиса» изменяют
обычные квитанции, а не фирменную картинку.

## Проверка

- Полный набор: 125 тестов. Ruff и форматирование проходят.
- После итоговой правки отступов и расширения диагностики повторены 6 профильных
  тестов сервисного листа и выпуска; все прошли.
- Визуально проверены окно Qt, одностраничный пример и обе страницы длинного листа.
  Более длинный непрерывный абзац, рекомендации и неизвестные поля покрыты тестами.
- Из распакованного ZIP выполнены `--self-test` и `--self-test-reopen` на вымышленных
  данных. Результат: `stage=passed`, `frozen=true`, версия 0.5.11, схема v7.
  Проверены архивный PDF после восстановления/перезапуска и печать сервисного листа
  в отдельный PDF. Просмотрен снимок окна из EXE и все 5 страниц инструкции.
- Рабочая база не открывалась для тестирования. Оригинальный DOC, данные машины из
  образца и проверочные БД не входят в Git или ZIP. Встроены только постоянные
  элементы бланка.

## Файлы и ограничения

Локальный каталог `artifacts/release-0.5.11` содержит переносимый ZIP, PDF-руководство
и SHA256SUMS.txt. Он не отслеживается Git; выпуск на GitHub не публиковался.
Исходники и сведения об изменении сохраняются в закрытом origin отдельно.
Печать на физическом принтере механика и его оценка удобства остаются проверкой на месте.
