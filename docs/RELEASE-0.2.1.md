# AutoService 0.2.1 — автомобили при запуске

12 ноября 2026. Изменение по обратной связи пользователя после успешной первой пробы.

- Автомобили открываются при запуске и стоят первыми в меню.
- Главная переименована в Звонки и поставлена второй; заголовок страницы также Звонки.
- Порядок: Автомобили → Звонки → Календарь → Финансы → Настройки.
- Ctrl+1 — автомобили, Ctrl+2 — звонки, Ctrl+3 — календарь; Ctrl+F — поиск машин.
- Поиск и обновление звонков корректно работают после перестановки разделов.

Схема SQLite v5 не менялась. Тестирование выполнялось на вымышленных данных;
рабочая база пользователя не открывалась. Для обновления закройте AutoService и
запустите новый установщик в прежнюю папку. Данные хранятся отдельно от программы.

## Проверено

80 тестов pytest, Ruff и форматирование проходят. Настоящие окна Windows и сочетания
клавиш проверены при обычном масштабе и дополнительном ×1,5; снимки просмотрены.
Конечный EXE и установленная программа проверены отдельными процессами: автомобили
открываются при запуске, Звонки ниже, навигация/поиск, PDF и печать в PDF, импорт,
копии/восстановление и сохранность после перезапуска. Установка, повторная установка
и удаление проверены в отдельном тестовом каталоге; SHA256 базы вокруг операций
установщика совпадает. Python и Qt загружены из папки выпуска.

Бумажная печать одной страницы на HP по USB подтверждена пользователем в предыдущей
проверке; в этой правке печать не менялась, повторный бумажный лист не отправлялся.
Отдельный чистый компьютер и другие принтеры не проверены. Реальных TXT и бланка пока
нет: совместимость именно с ними не заявляется. Установщик без сертификата издателя.
