# Решения первого этапа

1. Qt Widgets, стиль Fusion и светлая таблица стилей. Qt 6 обеспечивает
   масштабирование; ручные устаревшие флаги High DPI не используются.
2. QListWidget + QStackedWidget: пять экранов, Tab, стрелки, Ctrl+1…5.
   Демонстрационные строки живут только в памяти и явно обозначены.
3. SQLite хранится в `%LOCALAPPDATA%\AutoService\autoservice.sqlite3`.
   Резервный путь при отсутствии LOCALAPPDATA: `~/AppData/Local/AutoService`.
   Импорт Python-модулей не создаёт каталоги или базу.
4. Сейчас только `app_metadata` и `PRAGMA user_version = 1`.
   Инициализация транзакционная, повторный запуск сохраняет содержимое.
   Неизвестная непустая схема, чужая метка приложения или более новая версия
   вызывают отказ запуска без удаления базы. Следующие миграции потребуют
   отдельной реализации и резервного копирования.
5. Разделение UI, инициализации SQLite и пользовательских путей без ORM
   и дополнительных уровней абстракции. Рабочее подключение закрывается
   после инициализации. Бизнес-операции ещё не реализованы.
6. `requirements.in` задаёт прямые зависимости; `requirements.txt` фиксирует
   все фактически установленные версии. Обновления сначала проверяются тестами.
7. Запуск F5 задаёт интерпретатор явно. Терминал получает `.venv/Scripts` в PATH
   через настройки проекта; запуск Activate.ps1 и изменение ExecutionPolicy не нужны.

Контрольные точки для будущих локальных коммитов: «Каркас и окружение»,
«Автомобили», «История ремонтов». Коммитировать после проверок и оценки интерфейса.
Публикация в интернет не входит в текущую задачу.
