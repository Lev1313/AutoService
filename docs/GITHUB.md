# GitHub и сохранение версий

Репозиторий: https://github.com/Lev1313/AutoService — закрытый (private).
Локальный проект: C:/Projects/Autoservice. Основная ветка main, remote origin.
Пользователь разрешил настройку и синхронизацию 12 ноября 2026.

## После законченного этапа

1. Проверить текущую ветку, Git status и изменения пользователя.
2. Проверить функцию и относящиеся к ней сценарии; выполнить требуемые проверки
   из AGENTS.md. Для изменений только документации достаточно проверки diff.
3. Просмотреть состав коммита. Добавлять явно выбранные собственные файлы.
   Не включать базы, резервные копии, оригинальные TXT, ключи, токены и .venv.
4. Сделать локальный коммит, затем `git push` в настроенный origin текущей ветки.
   Обычная синхронизация после проверок уже разрешена; повторно не спрашивать.
5. Проверить совпадение удалённой и локальной ветки. При сбое сохранить локальную
   работу и сообщить, какая версия ещё не отправлена. Не применять force push.

Не создавать без согласования публичный репозиторий, новые направления отправки,
приглашения другим людям или платные службы. Не хранить токены в файлах и URL.
Вход выполняет штатный Git Credential Manager установленного Git.

## История и выпуск

Первая отправка включает всю историю от каркаса до выпуска 0.2.1.
Тег v0.2.1 указывает на коммит 925eea7 с проверенной новой навигацией.
Крупные Windows-пакеты не включаются в историю исходников; они сохранены в
материалах выпуска. Автоматическая публикация бинарных Releases отдельно не настроена.
GitHub хранит код и документы. Машины, ремонты, PDF и архив TXT находятся в базе:
их резервное копирование и перенос выполняются из Настроек AutoService.

Для восстановления кода на новом компьютере используйте Clone этого закрытого
репозитория в новую пустую папку, затем инструкции README.md и WINDOWS-RELEASE.md.
Не клонируйте поверх существующего рабочего проекта.
